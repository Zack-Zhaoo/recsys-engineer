# 前沿主张地图

作者未来三年的三项重点押注，不是按单一模型结构划分，而是分别回答推荐决策、推荐研发和推荐应用边界如何演进。

| 主张 | 核心问题 | 层次 |
|---|---|---|
| [Agentic Recommendation](agentic-recommendation.md) | 系统如何推理用户并做长期、可交互的推荐决策 | 推荐决策层 |
| [Auto RS](auto-rs.md) | 系统如何围绕目标自动发现问题、实验和迭代 | 推荐研发层 |
| [RS in AI](rs-in-ai.md) | 推荐如何成为 AI 原生产品和机器人的个性化基础设施 | 产品应用层 |

三条演进线可概括为：

```text
推荐决策 Agent 化
推荐研发自动化
推荐能力泛在化
```

它们可以共存：RS in AI 提供新的产品容器，Agentic Recommendation 负责用户理解与决策，Auto RS 负责让底层模型、数据和链路持续优化。

作者同时保留一条重要的反共识判断：[生成式推荐与 One Model 的边界](one-model-limits.md)。生成式能力值得研究，但端到端统一取代工业漏斗的价值和成熟度被高估。更可信的演进路线是模块化系统吸收生成能力，并由 Agent 和自动优化闭环协调。

这些文件是作者主张，不是已被行业证明的事实。使用时结合 `knowledge/` 的公开证据，说明当前成熟度与反证条件。
