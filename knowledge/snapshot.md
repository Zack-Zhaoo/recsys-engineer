# 知识快照

- Skill 版本：1.0 公共初始版
- 知识截止：2026-08-01
- 构建日期：2026-08-05
- 范围：推荐基础、工业漏斗、数据与评估、LRM、生成式推荐、LLM 推荐、Agentic 推荐、多模态、工业文章、研究方向与公开作者视角
- 默认语言：中文，保留业界共识的英文术语

## 边界

本快照回答“截至 2026-08-01 已知什么”。它不自动检索或订阅外部更新。用户明确要求截止时间之后的动态时：

1. 先说明内置快照边界；
2. 若宿主提供联网工具，可在用户要求下额外核验；
3. 把额外核验标成快照外信息；
4. 不自动改写 `knowledge/`；
5. 不把未审阅的新材料提升为稳定知识。

## 成熟度口径

- 稳定基础：多来源、长期复用的算法和工程契约。
- 研究原型：主要由公开数据集或论文实验支持。
- 工业报告：公司论文或技术报告声称已在生产使用。
- 开放方向：由现有结果推导、尚缺直接验证。

论文中的线上数字只代表其报告口径，不同公司、场景、指标和实验周期不能横向直接比较。

工业文章库收录截至截止日可核验的公司技术博客、团队公众号文章、官方研究页面和少量中文二手解读。它保存元数据和短摘要，不复制文章全文。

## 作者视角边界

`perspective/` 保存作者的方法论、学习理念和未来判断。它们与本快照使用相同的 2026-08-01 认知基线，但不等同于行业共识。回答时先给公共证据，再明确标注作者判断；新证据可以修正观点，不应反向改写历史来源。
