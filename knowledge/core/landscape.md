# 推荐系统全景

## 两个正交坐标

推荐知识同时沿两条轴组织：

1. **线上漏斗**：召回 → 预排 → 精排 → 重排/策略 → 曝光与反馈。
2. **范式演进**：经典深度推荐 → Large Ranking Model → 生成式推荐 → LLM 增强/直接推荐 → Agentic 推荐。

漏斗回答“模型在哪运行、上下游契约是什么”；范式回答“系统边界正在怎样变化”。

## 传统工业系统

- 召回从超大物料池构造覆盖足够、成本可控的候选集。
- 预排以低成本去掉明显弱候选，并尽量保持精排顺序。
- 精排估计点击、时长、转化、价值等目标。
- 重排把独立候选分数转换为满足多样性、约束和长期目标的列表。
- 曝光与行为继续生成训练数据，形成闭环。

各层独立优化带来目标不一致、样本选择偏差、重复计算和通信成本；它也带来清晰的灰度、回滚和组织分工。

## 截至 2026-08 的主要变化

- **LRM** 保留判别式打分，以硬件友好架构、长序列、MoE 和 token 化扩大排序模型。
- **GR** 把候选检索、下一物品或整个 session 表达为自回归生成，部分工作尝试统一召回和排序。
- **LLM 推荐** 利用语言知识处理冷启动、解释、画像、特征和开放世界意图，但受 grounding、成本和延迟约束。
- **Agentic 推荐** 把意图理解、记忆、规划、工具调用和反思变成系统控制层，而非单次前向模型。
- **融合趋势** 是 LRM 吸收 tokenization，GR 吸收工业特征与高效 Serving，Agentic 吸收 Semantic ID 和持久用户记忆。

## 当前判断

- 多阶段漏斗仍是大多数工业系统最稳健的执行骨架。
- LRM 是对现有精排链路改造阻力较小的扩展路线。
- GR 已出现生产报告，但端到端替换仍需要解决候选约束、解码、更新和回滚。
- Agentic 已有生产报告，当前更适合意图、解释、策略和编排等有界职责；完全接管高 QPS 主链路仍受可靠性与成本约束。
- “生成式”不等于“通用 LLM”：许多 GR 使用专门序列模型和离散物品 token。
