# 数据与采样

推荐效果的上限通常先由“记录了什么、如何成样、标签何时成熟”决定，再由模型决定。

## 数据链路

最小可追溯日志应覆盖 request、每级候选、过滤原因、模型与特征版本、分数、最终位置、曝光、交互及延迟结果。事件要有 event time 与 processing time，训练切片必须按可用时点回放，避免未来信息穿越。

## 样本定义

- 曝光未点不是天然负偏好，可能是位置、界面或注意力不足。
- 未曝光候选可用于召回/预排训练，但需要理解旧策略选择偏差。
- 点击、停留、收藏、成交和复访有不同噪声与延迟窗口；后置转化只在点击样本上可见，直接在该子空间训练会引入选择偏差。[SRC-ESMM-2018]
- 重复曝光、机器人、误触和退款等清洗规则必须版本化。

## 负采样

随机负例覆盖全局边界，in-batch negative 高效，曝光负例接近线上决策，hard negative 提升细粒度辨别。理想方案常是分层混合，并记录采样概率用于校正。假负例和热门物料过采样会扭曲表示空间；in-batch 负例的流行度偏差可用在线频次估计做 logit 校正。[SRC-SAMPLING-BIAS-2019]

## 防泄漏检查

1. 特征在预测时点是否真实可得？
2. 聚合窗口是否越过标签时点？
3. 同一用户/物料是否跨随机切分泄漏？
4. 负采样是否使用未来全集或未来热度？
5. 教师分数是否来自包含验证期数据的模型？

## 数据质量指标

事件覆盖、延迟分布、重复率、join 命中率、特征缺失、标签成熟度、分群样本量、采样权重分布和训练—线上分布偏移都应可观测。
