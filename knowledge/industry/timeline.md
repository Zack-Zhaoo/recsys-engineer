# 推荐系统演进时间线

| 时期 | 主线 |
|---|---|
| 1990s–2000s | 协同过滤、矩阵分解、Learning to Rank |
| 2010s 前半 | 大规模 LR/GBDT、Embedding、Wide & Deep、双塔召回 |
| 2010s 后半 | 深度特征交叉、注意力序列、多兴趣、多任务、图推荐 |
| 2020–2022 | Transformer 序列、超长行为、对比学习、多模态与预训练推荐 |
| 2022–2024 | P5/TALLRec 等 LLM 推荐；TIGER Semantic ID；HSTU Scaling；RecMind Agent |
| 2025 | OneRec/MTGR 等生成式工业化探索；RankMixer LRM；RecGPT/RecBot Agentic 路线 |
| 2026-01–08 | Kunlun/TRM/SIF 等继续推进 LRM 与统一 token；RecGPT-V3 引入状态化记忆和混合模态工业报告 |

时间线只标志公开代表方向，不表示前一代方法被淘汰。每个节点的来源见 [来源目录](../sources/catalog.yaml)。
