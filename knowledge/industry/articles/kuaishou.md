# 快手工业文章

## 生成式系统

- [KDD 2025｜个性化生成式 SUG](https://mp.weixin.qq.com/s/bUk8ThagHP2p4ldk7SZqbg)（2025）：搜索建议生成中的个性化与安全约束。[SRC-IND-KS-SUG-2025]
- [OneSearch：端到端生成式搜索](https://mp.weixin.qq.com/s/1pWKLt-dP64vPHLKRWRpyQ)（2025）：用统一生成框架重构搜索链路。[SRC-IND-KS-ONESEARCH-2025]
- [GR4AD：从 Token 到 Revenue 的广告全链路重构](https://mp.weixin.qq.com/s/tOvzW_fAecVyAquxQoN4Nw)（2026）：生成式广告推荐与商业价值约束。[SRC-IND-KS-GR4AD-2026]
- [HSRL：语义 ID 驱动的分层语义强化学习](https://mp.weixin.qq.com/s/OcrjrDD9zlT7UHoN9I7eFQ)（2026）：Semantic ID 与分层 RL 的结合。[SRC-IND-KS-HSRL-2026]
- [从“找视频”到“产视频”：RaG](https://mp.weixin.qq.com/s/df0isHri0xNsmfaFbJe3Ug)（2026）：从检索已有内容扩展到生成目标内容。[SRC-IND-KS-RAG-2026]
